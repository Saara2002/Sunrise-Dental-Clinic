❓ Help and User Guide

Sunrise Dental Clinic Management System

Welcome to Sunrise Dental Clinic

This Help section provides step-by-step instructions for using the Receptionist Management System. Follow the instructions below to manage patients, appointments and billing.

🔐 1. Login

Use your authorized username and password to access the system.

  1. Open the Sunrise Dental Clinic system.
  2. Enter your username.
  3. Enter your password.
  4. Click the Login button.
  5. You will be redirected to the appropriate dashboard.

📅 2. Register Appointment

To register a new patient appointment:

  1. Open Appointments.
  2. Click New Appointment.
  3. Enter the patient details.
  4. Select the dentist.
  5. Select the treatment.
  6. Select the appointment date and time.
  7. Click Register Appointment.

🔍 3. Search Appointment

Use the search box to find an existing appointment.

  1. Open the Appointments page.
  2. Click the search box.
  3. Enter the appointment number or patient name.
  4. The matching appointments will be displayed.

✏️ 4. Edit Appointment

Existing booked appointments can be updated.

  1. Open Appointments.
  2. Find the required appointment.
  3. Click the Edit button.
  4. Change the required information.
  5. Click Update Appointment.

❌ 5. Cancel Appointment

To cancel a booked appointment:

  1. Open the Appointments page.
  2. Find the required appointment.
  3. Click the Cancel button.
  4. Confirm the cancellation.
  5. The status will change to CANCELLED.

✅ 6. Complete Appointment

After the patient receives treatment:

  1. Open Appointments.
  2. Find the patient's appointment.
  3. Click Complete.
  4. Confirm the action.
  5. The appointment status will become COMPLETED.

👤 7. Patient Management

The Patients section can be used to view and search patient information.

  • View registered patients.
  • Search using patient name or phone.
  • View patient contact details.
  • View patient address.

💰 8. Generate Bill

Bills can be generated after completing an appointment.

  1. Open Billing.
  2. Select the relevant appointment.
  3. Check the treatment cost.
  4. Add the consultation fee if applicable.
  5. Check the total amount.
  6. Generate and save the bill.
⚠️ Important: Always check the patient name, appointment number, date and time before saving or updating an appointment.
